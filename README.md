### 🛠️ Selected Projects

* **[Memopops](https://github.com/SaqlainSQX/memopops)** — proof-carrying shared memory for AI agents, with evidence-backed propositions, immutable revisions, Z3 reasoning, and independent proof checking. **Python · FastAPI · FalkorDB · Z3**.
* **[DistriStore](https://github.com/CN-2026-IIITA/Distri_Store)** — peer-to-peer storage with concurrent encryption, erasure coding, and threshold-based access. **Python · FastAPI · Distributed Systems**.
* **[TradeIQ](https://github.com/sahsudhanshu/III5.0)** — multi-agent financial analysis combining forecasting, sentiment, graph context, and personalized risk reasoning. **[App](https://tradeiqiiita.vercel.app)**.
* **[Matsya AI](https://github.com/sahsudhanshu/ai-for-bharat)** — computer vision and tool-using agents for catch analysis and contextual insights. **LangGraph · Gemini · YOLO** · **[App](https://matsyaai.vercel.app)**.
